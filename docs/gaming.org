* Gaming layer

The gaming layers are configured in [[../miryoku/custom_config.h][custom_config.h]] for the left hand on the keyboard and the right hand on the mouse. Movement and gaming modifiers use immediate key presses, with no home-row modifiers or layer-tap keys.

From Base, hold the left bottom-row outermost key to activate Button, then double-tap the left half's innermost home-row key. Release the Button key after switching. Num Lock is on the right half's innermost home-row key on Button.

The left half's layout is shown in physical order, left to right:

#+BEGIN_EXAMPLE
Q      W      E      R      T
A      S      D      F      G
Z      X      C      V      Numbers
             Shift  Ctrl   Space
#+END_EXAMPLE

Hold Numbers (the former Gaming B position) to access:

#+BEGIN_EXAMPLE
1      2      3      4      5
6      7      8      9      0
B      Esc    Enter  Base   (held)
             Shift  Ctrl   Space
#+END_EXAMPLE

Release Numbers to return to Gaming. While holding Numbers, double-tap Base (the Gaming V position) to return to the normal typing layout. Gaming stays active until you return to Base. Shift, Ctrl, and Space stay available on both gaming layers. The top two rows send numbers while Numbers is held, so release it before issuing new movement key presses.

The right half remains available with Y U I O P / H J K L ' / N M , . /, and Enter, Escape, Base on its thumbs. All gaming controls above are accessible using only the left half. The normal utility layers are not accessible from Gaming.

Build and flash using your existing board and shield settings. The shared custom configuration adds Gaming to the existing keymap, so no build option is required. Keycodes follow the host keyboard layout, as on the other layers; this layout assumes the host maps those keycodes as QWERTY.
